# Abrir sesión

## Pasos

1. Leer `AGENTS.md` y `KAANBAL_IMPLEMENTATION_STATUS.md`.
2. Leer `SOFTWARE_FACTORY/docs/EXPOSURE_LIFECYCLE_BITACORA.md` si el objetivo toca deploy/exposición/VPN/bindings/instalador (o el usuario dice `continua bitácora exposición`).
3. Leer `AGENTS/STATE.md` y últimas 2 sesiones en `AGENTS/sessions/`.
4. `git pull` en repos activos (`software-factory`, `fago-sistema` si aplica).
5. Confirmar ticket Jira SF-XXX o proponer crear uno.
6. Resumir plan en 3-5 bullets antes de ejecutar.

## No hacer

- SSH al lab sin ticket y sin aprobación.
- Modificar código antes de confirmar alcance.
