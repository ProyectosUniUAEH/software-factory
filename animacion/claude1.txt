La nueva historia que vas a vivir
Acuaponsito ahora empieza DORMIDO (tu clip siesta-me-quede-dormido), flotante en la esquina inferior derecha — sin etiquetas de texto, el estado se ve, no se lee. Puedes arrastrarlo a donde quieras, nunca estorba. Si le das clic dormido, te susurra: "Zzz… conéctame un proveedor de IA para despertar 🌱".

El nuevo paso 1 es el Agente IA: eliges proveedor (DeepSeek recomendado primero, como pediste — también Claude y OpenAI, puedes conectar varios), pegas tu API key y das "Conectar y despertar ⚡". Cuando la key valida contra la API real: Acuaponsito despierta (transición con crossfade de 600ms — los cortes desaparecen porque tus clips terminan quietos), se enciende su anillo verde, y el LLM de verdad lo saluda: DeepSeek recibe el catálogo completo, responde el contrato JSON {say, state, clip}, y su texto aparece en la burbuja con efecto typewriter (lista para sincronizar voz después). Las keys terminan como Secret kaanbal-ai-providers en tu cluster — parte del sistema, no solo del instalador, para todos los agentes que vienen.

El framework — tu pieza reutilizable
En D:\SOFTWARE_FACTORY_SECRETS\animacion\ como pediste:

catalog.json — tus 4 clips catalogados con descripciones ricas para el LLM (mejoré tus títulos: sleep__siesta, greet__saludo, listen__atento-serio con nota de que su final serio conecta natural con think, think__esfuerzo), el árbol de estados con fallbacks (si no existe clip de wake, cae a greet automáticamente — nunca pantalla negra), y una wishlist con los prompts listos para tus 3 generaciones diarias (prioridad: wake y speak, cierran el ciclo conversacional).
ACUAPONSITO_FRAMEWORK.md — el framework completo: cómo funciona, el contrato LLM (a prueba de Haiku: una decisión de estado + una opcional de clip, equivocarse es barato), la guía humana de 3 pasos para agregar videos, y las reglas de generación que ya aprendiste con Gemini (escena ADN, último segundo quieto, boca-waveform nunca lip-sync).
Lo mejor: el instalador sirve los clips directo desde esa carpeta. Mañana generas un video, lo copias ahí, agregas su entrada al JSON, refrescas — y el LLM ya puede usarlo. Cero redeploy. Para reusarlo en otro proyecto: copias la clase AcuaBot de app.js, sirves la carpeta por HTTP, y le das al LLM el system prompt de la sección 6 del MD.
